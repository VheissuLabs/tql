# Schemas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On Postgres and SQL Server, list, browse, edit, inspect, export and complete the tables of every user schema, under folding schema headers, with `schema.table` names wherever a table outside the default schema is named.

**Architecture:** A `Table { schema, name }` type replaces bare table-name strings through the database layer, the schema caches, the browser and completion. A table in the default schema has `schema: None`, so MySQL, SQLite and every single-schema database behave exactly as today. Postgres and SQL Server list every user schema and resolve `None` to their default schema in their own queries. The sidebar becomes rows of schema headers and tables, folded like connection groups.

**Tech Stack:** Rust 2024, ratatui, `postgres`, `tiberius`, `rusqlite`, `mysql`. Tests with `cargo test`; live Postgres on Herd (`127.0.0.1:5432`, user `root`), live SQL Server in CI (`TQL_TEST_SQLSRV`).

**Spec:** `docs/superpowers/specs/2026-10-12-schemas-design.md`

## Global Constraints

- No code comments anywhere (a hook rejects them).
- `[lints.rust] warnings = "deny"` and `clippy::all = "deny"`: the build fails on any warning.
- Commit straight to `main`; push with `git push -q git@github.com:VheissuLabs/tql.git main`, then `git fetch -q origin`.

- A table in the default schema keeps its bare name everywhere. A table in any other schema is written `schema.table`.
- System schemas are never listed: Postgres `pg_catalog`, `information_schema`, `pg_toast*`, `pg_temp_*`; SQL Server lists only `sys.tables` with `is_ms_shipped = 0`, which already excludes `sys` and `INFORMATION_SCHEMA`.
- MySQL and SQLite: every table has `schema: None`; their SQL does not change.
- Never script keys against the user's saved connections. Live tests use Herd's local Postgres and scratch databases only.

## Review Focus

1. **A table with the same name in two schemas** (`public.orders` and `ev.orders`): the sidebar, the open table, edits, deletes, foreign keys and completion must each act on the right one, never the first match by name. Pinned in Task 3 (live Postgres) and Task 8 (completion).
2. **A name that contains a dot or needs quoting** (`"my.table"`, `"Order Lines"` in schema `"Ev"`): parsing, quoting and completion must not split inside quotes. Pinned in Task 1 and Task 8.
3. **Switching database (`b`) on a server whose databases have different schemas:** the default schema, the fold state and the sidebar rows must follow the new database. Pinned in Task 5.
4. **A connection whose user's default schema is not `public`/`dbo`** (Postgres `search_path` set to `ev`): `ev`'s tables are bare and `public`'s are qualified. Pinned in Task 3.
5. **A foreign key pointing into another schema:** following the link (`L`) and the inspector's related rows open `public.users`, not a missing `users` in the current schema. Pinned in Task 3.

```rust
use std::fmt;

#[derive(Debug, Clone, PartialEq, Eq, Hash, PartialOrd, Ord, Default)]
pub struct Table {
    pub schema: Option<String>,
    pub name: String,
}

impl Table {
    pub fn bare(name: impl Into<String>) -> Table {
        Table {
            schema: None,
            name: name.into(),
        }
    }

    pub fn in_schema(schema: impl Into<String>, name: impl Into<String>) -> Table {
        Table {
            schema: Some(schema.into()),
            name: name.into(),
        }
    }

    pub fn quoted(&self, quote: impl Fn(&str) -> String) -> String {
        match &self.schema {
            Some(schema) => format!("{}.{}", quote(schema), quote(&self.name)),
            None => quote(&self.name),
        }
    }

    pub fn parse(typed: &str) -> Option<Table> {
        let mut parts = split_name(typed.trim());
        match parts.len() {
            1 if !parts[0].is_empty() => Some(Table::bare(parts.remove(0))),
            2 if !parts[0].is_empty() && !parts[1].is_empty() => {
                let name = parts.remove(1);
                Some(Table::in_schema(parts.remove(0), name))
            }
            _ => None,
        }
    }

    pub fn resolve(typed: &str, tables: &[Table], default_schema: Option<&str>) -> Option<Table> {
        let wanted = Table::parse(typed)?;
        let same = |left: &str, right: &str| left.to_lowercase() == right.to_lowercase();
        let schema = wanted
            .schema
            .filter(|schema| default_schema.is_none_or(|default| !same(schema, default)));
        if let Some(found) = tables.iter().find(|table| {
            same(&table.name, &wanted.name)
                && match (&table.schema, &schema) {
                    (None, None) => true,
                    (Some(left), Some(right)) => same(left, right),
                    _ => false,
                }
        }) {
            return Some(found.clone());
        }
        if schema.is_some() {
            return None;
        }
        let mut elsewhere = tables
            .iter()
            .filter(|table| table.schema.is_some() && same(&table.name, &wanted.name));
        match (elsewhere.next(), elsewhere.next()) {
            (Some(only), None) => Some(only.clone()),
            _ => None,
        }
    }
}

impl fmt::Display for Table {
    fn fmt(&self, formatter: &mut fmt::Formatter<'_>) -> fmt::Result {
        match &self.schema {
            Some(schema) => write!(formatter, "{schema}.{}", self.name),
            None => formatter.write_str(&self.name),
        }
    }
}

pub fn split_name(typed: &str) -> Vec<String> {
    let mut parts = vec![String::new()];
    let mut closing: Option<char> = None;
    for character in typed.chars() {
        let part = parts.last_mut().expect("there is always a part");
        match closing {
            Some(close) if character == close => closing = None,
            Some(_) => part.push(character),
            None => match character {
                '"' => closing = Some('"'),
                '`' => closing = Some('`'),
                '[' => closing = Some(']'),
                '.' => parts.push(String::new()),
                other => part.push(other),
            },
        }
    }
    parts
}
```

```rust
use super::*;
use crate::updates::Remembered;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SidebarRow<'a> {
    Schema {
        name: &'a str,
        count: usize,
        folded: bool,
    },
    Table(&'a Table),
}

#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct Folds {
    pub folded: Vec<String>,
    pub open: Vec<String>,
}

impl Browser {
    pub fn sidebar_rows(&self) -> Vec<SidebarRow<'_>> {
        let needle = self.filter.to_lowercase();
        let matching = |table: &&Table| table.to_string().to_lowercase().contains(&needle);
        let default = self.default_schema.as_deref().unwrap_or("default");

        let mut schemas: Vec<(&str, Vec<&Table>)> = Vec::new();
        for table in &self.tables {
            let schema = table.schema.as_deref().unwrap_or(default);
            match schemas.iter_mut().find(|(name, _)| *name == schema) {
                Some((_, tables)) => tables.push(table),
                None => schemas.push((schema, vec![table])),
            }
        }
        if schemas.len() <= 1 {
            return self.tables.iter().filter(matching).map(SidebarRow::Table).collect();
        }
        schemas.sort_by_key(|(name, _)| (*name != default, name.to_lowercase()));

        let mut rows = Vec::new();
        for (name, tables) in schemas {
            let shown: Vec<&Table> = tables.iter().copied().filter(matching).collect();
            if !needle.is_empty() && shown.is_empty() {
                continue;
            }
            let folded = needle.is_empty() && self.is_folded(name);
            rows.push(SidebarRow::Schema { name, count: tables.len(), folded });
            if !folded {
                rows.extend(shown.into_iter().map(SidebarRow::Table));
            }
        }
        rows
    }

    pub fn is_folded(&self, schema: &str) -> bool {
        if self.folds.folded.iter().any(|folded| folded == schema) {
            return true;
        }
        if self.folds.open.iter().any(|open| open == schema) {
            return false;
        }
        Some(schema) != self.default_schema.as_deref()
    }

    pub(super) fn fold_schema(&mut self, schema: &str, folded: bool) {
        self.folds.folded.retain(|name| name != schema);
        self.folds.open.retain(|name| name != schema);
        match folded {
            true => self.folds.folded.push(schema.to_string()),
            false => self.folds.open.push(schema.to_string()),
        }
        self.table_index = self
            .sidebar_rows()
            .iter()
            .position(|row| matches!(row, SidebarRow::Schema { name, .. } if *name == schema))
            .unwrap_or(0);
        self.remember_folds();
    }

    fn folds_key(&self) -> String {
        format!(
            "tables.folded.{}.{}",
            self.connection.id,
            self.active_database.clone().unwrap_or_default()
        )
    }

    fn remember_folds(&self) {
        let Some(store) = &self.store else {
            return;
        };
        let saved = serde_json::json!({ "folded": self.folds.folded, "open": self.folds.open });
        Remembered::new(store).write(&self.folds_key(), &saved.to_string());
    }

    pub(super) fn recall_folds(&mut self) {
        self.default_schema = self.database.default_schema();
        self.folds = self
            .store
            .as_ref()
            .and_then(|store| Remembered::new(store).read(&self.folds_key()))
            .and_then(|saved| serde_json::from_str::<serde_json::Value>(&saved).ok())
            .map(|saved| {
                let names = |key: &str| -> Vec<String> {
                    saved[key]
                        .as_array()
                        .into_iter()
                        .flatten()
                        .filter_map(|name| name.as_str().map(String::from))
                        .collect()
                };
                Folds { folded: names("folded"), open: names("open") }
            })
            .unwrap_or_default();
    }
}

fn quoted_part(name: &str, lookup: &dyn Lookup) -> String {
    if needs_quoting(name) { lookup.quote(name) } else { name.to_string() }
}

fn written(table: &Table, lookup: &dyn Lookup) -> String {
    match &table.schema {
        Some(schema) => format!("{}.{}", quoted_part(schema, lookup), quoted_part(&table.name, lookup)),
        None => quoted_part(&table.name, lookup),
    }
}

fn schema_names(tables: &[Table]) -> Vec<String> {
    let mut names: Vec<String> = Vec::new();
    for schema in tables.iter().filter_map(|table| table.schema.clone()) {
        if !names.contains(&schema) {
            names.push(schema);
        }
    }
    names
}

fn table_candidates(tables: &[Table], lookup: &dyn Lookup) -> Vec<Candidate> {
    let mut candidates: Vec<Candidate> = schema_names(tables)
        .into_iter()
        .map(|schema| Candidate {
            text: quoted_part(&schema, lookup),
            label: schema,
            kind: Kind::Schema,
            note: None,
        })
        .collect();
    candidates.extend(tables.iter().map(|table| Candidate {
        text: written(table, lookup),
        label: table.name.clone(),
        kind: Kind::Table,
        note: table.schema.clone(),
    }));
    candidates
}

fn resolved(parts: &[String], schema: &Schema) -> Option<Table> {
    let typed = match parts {
        [name] => Table::bare(name.clone()),
        [schema_name, name] => Table::in_schema(schema_name.clone(), name.clone()),
        _ => return None,
    };
    Table::resolve(&typed.quoted(|part| format!("\"{part}\"")), schema.tables, schema.default_schema)
}
```
