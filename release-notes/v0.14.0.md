v0.14.0

Four new kinds of database, schemas, and completion that knows them.

New Features

- Postgres and SQL Server list the tables of every schema under folding
  headers, remembered per connection and database. A table outside your
  default schema is named schema.table everywhere: the grid, the palette,
  links, exports, tql tables, tql describe, tql export and the MCP tools.
- Completion offers schemas and the tables in them, narrows to a schema after
  "schema.", and completes the columns of schema.table and its alias (#5).
- DuckDB files open in tql, with their schemas, every DuckDB type shown
  readably, and editing by primary key.
- libSQL and Turso connections, by URL and auth token, over Turso's HTTP API,
  with editing as SQLite has.
- ClickHouse connections over its HTTP interface, browse and query only, with
  every ClickHouse type shown exactly.
- Redis and Valkey connections open a key browser: folding : namespaces
  scanned in the background, a view for every type, edits written together on
  :w, TTL, rename, database switching and a command pane. On Redis 7.4 and
  Valkey 9 a hash shows each field's TTL and T sets it; :log shows the command
  log (Valkey) or slow log (Redis).
- tql open and :open take a DuckDB file, libsql:// and https://…?authToken=
  URLs, and clickhouse://, redis:// and valkey:// URLs and their TLS forms.
  TablePlus import brings ClickHouse and DuckDB connections over.

Enhancements

- The status line shows the cursor's row among all the table's rows, 105 of
  5,000,000, in place of the column position. Filtered tables and small ones
  are counted exactly; a big Postgres, MySQL or SQL Server table shows the
  database's own estimate, ~4.9M, rather than wait on a full count.
- sql_keyword_case (in [ui] and the settings screen) sets the case completion
  writes keywords in: match (how you type, as before), upper or lower. A
  config file from an earlier tql is offered it on first run.
- Enter takes a completion as tab does.

Bug Fixes

- The insert-mode cursor in the SQL editor and the Redis command pane sits
  right after the text, not a row down and a column over.
