v0.13.0

Settings on a screen, and one set of commands everywhere.

New Features

- Change your settings without opening a file. tql settings, :settings, or
  Settings in the ctrl+k palette opens every setting on one screen, under UI,
  Theme, Updates, AI, MCP and Icons sections that fold. A change takes effect at
  once and is written to config.toml straight away: that one line, your
  comments and order kept, and a setting your file does not have yet is added
  with its comment.
- Each setting is edited the way it reads: enter flips one that is on or off,
  ← and → step through choices such as sql_editor, row_style and the theme
  colours, numbers are typed and held to their range, x puts a setting back to
  its default, and / finds one by name. The highlighted setting shows what it
  does, a value you have changed is drawn in your edited colour, the AI key is
  never shown, and the few tql reads only as it starts, such as mouse, say so.
- The connection list has a ctrl+k palette too, with its commands and every
  connection by name: type part of one and press enter to open it.
- A command that needs the screen runs from the shell and opens tql on it:
  tql new opens the new connection form, and tql sql and tql history open the
  SQL editor or the query history on the connection you name, or ask for one
  first.

Enhancements

- One list of commands sits behind :, both palettes and the shell, so a command
  has one name wherever you type it. A command typed on the wrong screen says
  where it works, such as ":sql works once a connection is open".
- The palette matches a command by its name as well as its description, so
  typing settings runs the command ahead of a table that happens to be called
  settings.
