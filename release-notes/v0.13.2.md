v0.13.2

More of tql's shell commands, from inside tql.

New Features

- :update checks for a newer tql and installs it while you keep working. The
  status bar says it is checking, then what it found: that you have the latest,
  that it is updating, or why it could not. It is the same check tql update
  runs, on the connection list or with a connection open.
- :open takes a SQLite file or a mysql://, pgsql:// or sqlsrv:// connection
  string and switches to it, saved to the connection list the way tql open
  saves it, and one you already have is reused rather than saved twice. :open
  on its own waits on the command line for the path.
- :export database writes every table in the database you are in to one .sql
  file, beside :export for the table on screen.
- :v and :version say which version of tql you are running.
- :help and :h open help, as ? does.

Enhancements

- All of these are in the ctrl+k palette too, and the help screen and
  docs/keys.md list them.
