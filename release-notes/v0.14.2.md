v0.14.2

Open a saved connection by name, straight from the shell.

New Features

- tql connect <connection> skips the connection list and opens the saved
  connection you name, as if you had picked it there. --db=<database> opens
  another database on the same server for that session, without changing
  what is saved; on SQLite and DuckDB, which are one database, it says so.
  A path or connection string given to connect still opens it the way tql
  open does. Thanks to Jerry Lopez (#7).

Bug Fixes

- tql connect with a database file that is not there yet says No such file,
  as tql open does, rather than that no connection has that name.
