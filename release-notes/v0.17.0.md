v0.17.0

Snowflake key pair and SSO sign-in from @jimbojsb, sign-out, and connections that come back after the laptop sleeps.

New Features

- Snowflake connections sign in with a key pair: the user's login name and
  the path to their RSA private key, PKCS#8 (encrypted or not) or PKCS#1,
  with an encrypted key's passphrase saved as the password. tql signs a fresh
  JWT before the last one runs out. authenticator=snowflake_jwt and
  private_key_path=… in a connection string. Thanks to @jimbojsb (#13).
- Snowflake connections sign in through SSO in the browser
  (authenticator=externalbrowser): tql opens your identity provider directly
  and takes the session it hands back, so accounts without the built-in OAuth
  integration the browser sign-in needs can sign in too. The session is saved
  with the connection and renewed without the browser while Snowflake allows,
  and large answers Snowflake keeps in cloud storage are gathered in
  parallel. Thanks to @jimbojsb (#13).
- The connection form asks a Snowflake connection how to sign in: access
  token, key pair, browser sign-in or SSO through the browser, and offers the
  PEM private keys in ~/.snowflake, ~/.ssh and the current directory. A
  connection saved by 0.16.0 with no access token keeps signing in through
  the browser.
- :sign-out on the connection list forgets the browser sign-in saved with the
  highlighted Snowflake connection, so it signs in afresh next time.

Bug Fixes

- A connection the server dropped while the laptop slept comes back on its
  own. MySQL and Postgres check a connection that has sat idle for half a
  minute and connect again before the next statement, so it just runs and
  nothing is sent twice. A connection through SSH starts its tunnel again
  first, and SQL Server and ClickHouse use the new tunnel too (#14).
- A copied Snowflake connection string keeps its warehouse, role, sign-in and
  private key path (#13).

Enhancements

- Every dependency is on its latest release, the RustCrypto crates behind
  saved passwords included; passwords saved before read back as they did.
