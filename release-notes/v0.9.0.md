v0.9.0

SQL Server on macOS, and a way in for scripts and agents.

New Features

- SQL Server is built into the macOS binary: sqlsrv and pdo_sqlsrv are
  bundled, so Microsoft's ODBC driver is the only thing left to install. When
  Homebrew's default OpenSSL is not openssl@3, tql relaunches itself with the
  driver pointed at the right one.
- Paging for SQL Server uses `offset N rows fetch next M rows only`, with
  `order by (select null)` added when a statement has no order, instead of
  `limit`/`offset`. This applies everywhere tql pages: the grid, related
  records, exports and the SQL editor's jump to a page.
- TLS for SQL Server comes from `ssl_mode`: encrypted by default, `disable`
  turns it off, and the server certificate is trusted unless `ssl_mode` is
  `verify-ca` or `verify-full`.
- Connection errors now say what to do: install OpenSSL 3, or install
  Microsoft's ODBC driver, with the commands for macOS and a link for Linux.
- `tql connections`, `tql tables`, `tql describe` and `tql query` let a script
  or an agent read your databases from the shell, read-only, with the same
  answers the MCP server gives. In a terminal they print a table; when piped or
  captured they print JSON. `--table` and `--json` force either, and
  `--database=` reads another database on the same server.
- `tql query <connection> "select …"` runs a single read-only statement
  (`select`, `show`, `explain`, `describe`, `pragma` or `with`), taking it from
  stdin or `-` when not given, with `--limit` capping the rows at 200. A
  refusal or a database error goes to stderr with a non-zero exit code.
- The palette and `:` line gained `create database <name>` and
  `drop database <name>`. Creating one switches to it. In the database list,
  typing a name that is not there offers a final `+ create <name>` row, and
  `ctrl+d` drops the highlighted database after putting
  `:drop database <name>` on the command line for you to confirm.
- Updates are staged into a `.tql-versions` folder beside the binary and
  switched to with a symlink at the next start, so a running tql, an MCP
  server included, keeps its own file. The last three versions are kept.

Enhancements

- The `[theme] grid` setting and its `inherit` value are gone. Column
  separators and the header rule are always drawn in the pane's border colour:
  `focus_border` when the pane is focused, `border` when it is not. A frame now
  reads as a single piece.
- Statements run through `tql query` are recorded in the same query history as
  editor and MCP runs, and the history's hint labels the source of any
  non-editor run, not just MCP.
- The pickers (databases, related tables and the connection form's file list)
  let every letter, `j`, `k` and `q` included, type into the filter. Movement
  is with the arrow keys or the new `ctrl+p` and `ctrl+n`.
- Dropping the database in use moves to another database first, and both
  create and drop are refused on SQLite and on a read-only connection.
- The MCP tools go through the same access layer as the new commands, so both
  give the same answers.

Bug Fixes

- Paging against SQL Server used `limit`/`offset`, which it rejects. It now
  uses `offset … rows fetch next … rows only`.
- Inserting a row where every column has a default wrote SQLite's
  `values ()` on every driver. It now writes `insert into t () values ()` on
  MySQL and MariaDB, and `insert into t default values` on SQLite, Postgres
  and SQL Server.
