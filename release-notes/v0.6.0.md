v0.6.0

A real SQL editor.

New Features

- `sql_editor` in `[ui]` chooses how the SQL editor takes your keys. `"simple"`
  is the default; `"vim"` gives a vim editor.
- The simple editor runs the statement under the cursor with ctrl+r, adds a
  line with enter, indents and outdents with tab and shift+tab, and undoes and
  redoes a word at a time with ctrl+z and ctrl+y.
- The vim editor has counts, motions, operators and text objects (`ci(`
  rewrites a subquery even across several lines), a register, undo and redo on
  u and ctrl+r, `.` to repeat the last change, visual and visual-line modes,
  and the current mode in the pane title: NORMAL, INSERT, VISUAL or
  VISUAL LINE.
- `:r` runs the statement under the cursor and, in visual mode, only the
  selection. `:run` is the same command.
- When the buffer holds several statements separated by `;`, only the one the
  cursor is in runs, and the status line names it, such as `statement 2 of 3`.
  A `;` inside quotes, a comment or a Postgres `$$` body does not split a
  statement.
- A new line starts at the indentation of the line before it.
- Clicking a pane focuses it, its border and title included. Clicking the table
  list or the rows leaves the SQL editor.

Enhancements

- Enter no longer runs the editor's statement; it adds a line. The pane's hints
  and the README say so: `ctrl+r runs it · ↵ adds a line · esc returns` for the
  simple editor, and `i types · :r runs it · esc returns` for vim.
- In the simple editor, tab and shift+tab indent and outdent the current line
  by two spaces rather than cycling panes. Leave with esc, alt+1, alt+2, or a
  click on another pane.
- `:r` runs the statement from inside the SQL editor and reloads the table from
  anywhere else. `:reload` always reloads, and the command line hints which one
  `:r` will do.
- In vim, ctrl+r is redo, not run; running the statement is `:r`.
- The pane's key hints follow the mode, and the visual selection is
  highlighted. In vim normal mode, tab and shift+tab move between panes; in
  insert mode they indent and outdent.
- Clicking a table in the table list keeps the focus on the list rather than
  jumping back to the grid.
